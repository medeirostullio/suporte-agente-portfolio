# Segurança e confidencialidade

Este repositório possui finalidade exclusivamente demonstrativa e não contém o código operacional da aplicação.

## Conteúdo proibido

Não devem ser publicados neste repositório:

- credenciais;
- senhas;
- tokens;
- certificados com chave privada;
- chaves de recuperação BitLocker;
- nomes reais de servidores;
- domínios corporativos;
- endereços internos;
- caminhos de rede;
- nomes reais de usuários;
- logs corporativos;
- números de série;
- endereços MAC;
- detalhes da infraestrutura;
- configurações de produção.

## Dados demonstrativos

Todos os nomes, domínios, usuários, equipamentos, identificadores e resultados apresentados neste repositório devem ser fictícios.

## Comunicação de exposição acidental

Se alguma informação potencialmente sensível for identificada, o conteúdo deverá ser removido e revisado antes de uma nova publicação.
